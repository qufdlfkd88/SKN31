# LangChain이란?

LangChain은 **대규모 언어 모델(LLM)을 활용한 애플리케이션을 더 쉽게 개발할 수 있도록 도와주는 프레임워크**입니다. 단순히 모델에 질문을 보내고 답을 받는 수준을 넘어, 여러 단계의 처리 흐름을 구성하고, 외부 데이터와 도구를 연결하며, 복잡한 AI 기능을 체계적으로 만들 수 있게 해줍니다.

## 핵심 목적

LLM은 단독으로도 유용하지만, 실제 서비스에 적용하려면 다음과 같은 기능이 자주 필요합니다.

- 문서나 DB 같은 **외부 데이터 연결**
- 검색 결과를 바탕으로 답변하는 **RAG(Retrieval-Augmented Generation)** 구현
- 여러 단계의 작업을 순차적으로 실행하는 **워크플로우 구성**
- 함수 호출, API 호출, 에이전트 동작 같은 **도구 사용**
- 프롬프트 관리, 메모리, 출력 파싱 등 **애플리케이션 레벨 기능**

LangChain은 이런 요소들을 표준화된 방식으로 묶어주어, 개발자가 LLM 중심 애플리케이션을 빠르게 만들고 확장할 수 있게 합니다.

## 주요 구성 요소

### 1. LLM/Chat Model 연결

다양한 모델 제공자(OpenAI, Anthropic, Google, 로컬 모델 등)의 API를 통합된 방식으로 다룰 수 있습니다. 이를 통해 모델을 교체하거나 여러 모델을 함께 사용하는 작업이 쉬워집니다.

### 2. 프롬프트 관리

LangChain은 프롬프트 템플릿을 구조적으로 관리할 수 있게 해줍니다. 입력 변수를 분리해 두고, 동적으로 프롬프트를 생성하거나 재사용하기 좋습니다.

### 3. 체인(Chain)

여러 작업을 연결해 하나의 흐름으로 만드는 기능입니다. 예를 들어:

- 질문을 입력받는다
- 관련 문서를 검색한다
- 검색된 문서를 요약한다
- 최종 답변을 생성한다

이처럼 단계별 작업을 하나의 체인으로 구성할 수 있습니다.

### 4. 에이전트(Agent)

에이전트는 LLM이 상황에 따라 어떤 도구를 사용할지 스스로 판단하도록 돕는 기능입니다. 예를 들어 검색, 계산기, 데이터베이스 조회, 외부 API 호출 등을 필요에 따라 선택하게 만들 수 있습니다.

### 5. 메모리(Memory)

대화형 애플리케이션에서는 이전 대화 내용을 기억하는 기능이 중요합니다. LangChain은 대화 기록을 저장하고 활용하는 메모리 기능을 제공합니다.

### 6. 검색 및 RAG

LangChain은 벡터 저장소, 검색기, 문서 로더 등을 연결해 RAG 시스템을 쉽게 구성할 수 있습니다. 이 방식은 모델이 학습하지 않은 최신 정보나 사내 문서를 기반으로 답변할 때 매우 유용합니다.

## LangChain의 장점

- **빠른 개발**: 복잡한 LLM 앱을 빠르게 프로토타입할 수 있습니다.
- **확장성**: 여러 모델, 도구, 저장소와 연결하기 쉽습니다.
- **모듈화**: 기능별로 잘 나뉘어 있어 유지보수가 편합니다.
- **생태계 지원**: 관련 라이브러리와 예제가 많아 학습과 적용이 비교적 쉽습니다.

## 주의할 점

- 프레임워크가 제공하는 추상화가 편리한 대신, 구조를 잘 이해하지 않으면 흐름이 복잡해질 수 있습니다.
- 버전이 바뀌면서 API 구조가 달라질 수 있어 문서를 함께 확인하는 것이 중요합니다.
- 단순한 LLM 호출만 필요한 경우에는 오히려 과한 도구일 수 있습니다.

## 한 줄로 정리하면

LangChain은 **LLM을 활용한 실제 애플리케이션을 만들기 위한 도구 상자이자 오케스트레이션 프레임워크**라고 볼 수 있습니다. 모델 호출, 문서 검색, 도구 사용, 대화 메모리, 워크플로우 구성 등을 한 번에 다루게 해주는 것이 핵심입니다.

## 어떤 경우에 유용한가?

- 챗봇을 만들고 싶을 때
- 사내 문서 기반 QA 시스템을 만들고 싶을 때
- 여러 API를 조합하는 AI 에이전트를 만들고 싶을 때
- LLM 출력 결과를 후처리하고, 조건에 따라 다른 작업을 수행하고 싶을 때
