Python 3.14 주요 변경 사항 요약

- 언어/런타임 핵심 변화
  - 주석(annotation)의 지연 평가가 도입되어, 함수/클래스/모듈의 annotation이 즉시 평가되지 않고 필요할 때만 평가된다.
  - 표준 라이브러리에 여러 인터프리터 지원이 추가되어, 하나의 프로세스 안에서 분리된 Python 인터프리터들을 사용할 수 있다.
  - 템플릿 문자열(t-strings)이 추가되어, f-string과 비슷한 문법으로 문자열의 정적 부분과 삽입값을 분리해 다룰 수 있다.
  - except 및 except* 표현식에서 대괄호 없이도 사용할 수 있도록 문법이 완화되었다.
  - finally 블록 안의 제어 흐름에 대한 제한이 조정되었다.
  - CPython용 안전한 외부 디버거 인터페이스가 추가되어, 실행 중인 프로세스에 안전하게 디버거/프로파일러를 붙일 수 있다.

- 성능 및 구현 개선
  - 새로운 인터프리터 타입이 추가되어 일부 환경에서 성능 향상이 기대된다.
  - free-threaded 모드가 더 성숙해졌고 공식 지원이 강화되었다.
  - 점진적 가비지 컬렉션이 도입되었다.
  - 오류 메시지가 전반적으로 개선되었다.

- 표준 라이브러리 개선
  - compression.zstd 모듈이 추가되어 Zstandard 압축을 지원한다.
  - asyncio의 introspection 기능이 강화되었다.
  - warnings 제어가 더 안전해졌다.
  - REPL과 일부 표준 라이브러리 CLI에 구문 강조 및 색상 출력이 추가되었다.
  - concurrent.futures.InterpreterPoolExecutor가 추가되었다.

- C API / 플랫폼 / 배포
  - Python 설정용 C API가 개선되었다.
  - Emscripten이 공식 지원 플랫폼(tier 3)으로 추가되었다.
  - free-threaded Python이 공식적으로 지원된다.
  - 공식 릴리스의 PGP 서명은 중단되었다.
  - Windows와 macOS 바이너리 릴리스가 실험적 JIT 컴파일러를 지원한다.
  - Android용 바이너리 릴리스가 새로 제공된다.

- 한줄 정리
  - Python 3.14는 annotation, 멀티 인터프리터, t-strings 같은 언어 기능과 함께, 표준 라이브러리/성능/디버깅/플랫폼 지원이 크게 확장된 버전이다.
